# Menkerud Home Asset Pack

These assets were separated from the generated Menkerud Home art-board so Claude Code can use them as individual files.

## Important
- `reference/dashboard-concept.png` is the visual target.
- `backgrounds/home-day.png`, `home-evening.png`, and `home-night.png` are individually generated production backgrounds normalized to the exact 1920×1080 landscape target. CSS gradients, glass, shadows and animation should still remain CSS rather than being baked into these images.
- The main implementation target remains 1920×1080 landscape.
- `Ring Mor`, `Ring Far`, and `Jeg er hjemme` stay in one row.
- `I DAG`, `HUSK...`, and `KVELD` stay in one row.
- Prefer CSS/SVG for glow, glass, ring waves, pushpins and status indicators when it gives cleaner scaling.
- The avatar artwork is placeholder artwork, not intended to represent actual family members.

## Folders
- backgrounds/ — day, evening and night scenery
- avatars/ — placeholder parent avatars
- icons/ — home/call/reminder icons
- notes/ — note artwork
- ui/ — glass/glow/ring-wave reference pieces
- status/ — status indicators
- decoration/ — small decorative elements
- reference/ — complete dashboard visual target
